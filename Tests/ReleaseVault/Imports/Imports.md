# Imports

The PDFs Graphite's notebook import writes for the four synthetic notebooks of `Tests/SyntheticNotebooks` (made from the documented formats by the import's own tests, nothing from a real notebook), by the import's own conversion in `ReleaseVaultGraphiteFilesTests`. Their recordings are left out: an audio file in the vault could play.

- [[Synthetic lecture.pdf]] (Goodnotes): pages of different paper, ink, a picture, an outline entry and a bookmark.
- [[Synthetic text boxes.pdf]] (Goodnotes): text boxes.
- [[Synthetic note.pdf]] (Notability): one long page cut into pages, with ink.
- [[Synthetic typed note.pdf]] (Notability): typed text as text boxes, running onto a second page.

The notebooks themselves are in [[Notebooks]]; the release pass imports them again as a person does.
