# Colours, links and line breaks

Syntax the other notes leave out.

## Colours by name

The Colors core plugin's palette by name: ~={red}red=~, ~={orange}orange=~, ~={yellow}yellow=~, ~={green}green=~, ~={cyan}cyan=~, ~={blue}blue=~, ~={purple}purple=~ and ~={pink}pink=~, and a colour inside a highlight: ==a ~={blue}blue=~ word==.

## A highlight across a formula

==The rate $f_s = 1 / T$ sets the band== stays one highlight.

## Colours in HTML are not tags

<span style="color:#ccc">This grey text</span> names `#ccc` in its style, which is not a tag; #real-tag is one.
