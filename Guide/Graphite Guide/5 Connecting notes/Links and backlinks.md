# Links and backlinks

## Link to a note

**Copy this**

```markdown
Tonight: [[Tomato soup]], then [[Lemon cake]].
```

**What you see**

Tonight: [[Tomato soup]], then [[Lemon cake]].

Type `[[` and start typing a note's name: Graphite suggests the notes that match. Tap a link to open it; ⌘ with the click opens it in a new tab. On the Mac, holding the pointer over a link (on iPad, the Pencil hovering) shows the note in a small card.

## Other words for the link

**Copy this**

```markdown
Have you tried [[Pancakes|the Sunday pancakes]]?
```

**What you see**

Have you tried [[Pancakes|the Sunday pancakes]]?

## A heading or a paragraph inside a note

**Copy this**

```markdown
[[Tomato soup#Ingredients]]
```

**What you see**

[[Tomato soup#Ingredients]]

Type `#` after the note's name to pick a heading, or `#^` for a single paragraph.

## A note that does not exist yet

[[Mushroom soup]] is a link to a note nobody has written. Follow it and Graphite makes the note, ready for you to write. It is a good way to plan: link first, write later.

## Backlinks: who links here

Every link works both ways. Open the right sidebar (**Sidebar** at the top right on iPad, **More** › **Links and Outline** on iPhone, **Sidebar** on the Mac) and choose **Backlinks**: it lists every note that links to this one, with the line of each link. Open [[Tomato soup]] and look: this note is there.

**Unlinked mentions** lists places where a note's name is written without a link; **Link** turns one into a link.

## Renaming keeps links working

Rename a note (touch and hold it in the sidebar, or right-click on the Mac, › **Rename…**) and Graphite offers to update every link to it.
