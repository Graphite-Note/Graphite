# Search

Search reads the name and the text of every note. On iPad and iPhone type in **Search** in the sidebar; on the Mac use **Search** at the top right of the window. ⇧⌘F goes straight there.

A few words narrow it down. The search field suggests them as you type.

| Type | Finds |
| --- | --- |
| `soup` | notes with a word starting with *soup* |
| `"lemon cake"` | the exact words together |
| `tag:#recipe` | notes with that tag |
| `path:Restaurants` | notes in a folder whose path has that word |
| `folder:Reading` | folders by part of their name |
| `[cuisine:Portuguese]` | notes whose property has that value |
| `section:Ingredients eggs` | *eggs* under a heading called Ingredients |
| `task-todo:` | every unticked task |
| `soup -tomato` | *soup* but not *tomato* |
| `soup OR cake` | either word |

**Bookmark This Search** keeps a search you use often in the **Bookmarks** panel.

## The other ways to find things

- **Quick Switcher** (⌘O): opens a note as you type part of its name. If none matches, it offers to make one.
- **Command Palette** (⌘P on iPad, ⇧⌘P on the Mac): runs any command by name, such as *Insert table* or *Open graph view*.
- **Filter** at the top of the file list (⌥⌘J): keeps only the files and folders whose names match.
- In the open note, **Find** (⌘F).
