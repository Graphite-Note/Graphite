# What a vault is

In Goodnotes or Notability, your notebooks live *inside the app*. You see them in the app's library, but you cannot see the files themselves, and another app cannot open them without an export.

Graphite works the other way round. **A vault is an ordinary folder.** Every note, notebook, drawing and PDF in it is a file you can see in the Files app on iPad and iPhone, or in the Finder on the Mac. Graphite opens the folder and edits the files where they are.

> [!example] This guide is a vault
> The notes you are reading are files in a folder called *Graphite Guide*. On iPad, open the **Files** app › **On My iPad** › **Graphite** and you will find it, with a file for every note you see in the sidebar.

## Why it is good for you

- **You own the files.** Nothing is locked in a format only one app reads. If Graphite disappeared tomorrow, every file would still open: notes in any text editor, notebooks in any PDF reader, drawings in Photos or Preview.
- **You choose where they live.** On the device, in iCloud Drive, in another cloud drive, on a USB stick. See [[Where a vault can live]].
- **Other apps can join in.** Obsidian opens the same folder. The Files app, Finder, Preview, Spotlight and Time Machine all see your notes as they see any file.
- **Sharing is sharing a folder.** Share one folder of a vault with a classmate or your family through iCloud Drive, and you both work in it. See [[Sharing a folder]].

## What is in a vault

| What you make in Graphite | The file it is | Opens in |
| --- | --- | --- |
| A note | `Recipe.md`, plain text written in Markdown | any text editor, Obsidian |
| A notebook | `Week 1 notebook.pdf`, a PDF with paper and your ink | any PDF reader |
| A drawing in a note | `Drawing 2026-11-16.png`, a picture | Photos, Preview, a browser |
| A lecture recording | `Lecture 2026-11-16.m4a`, audio | Music, QuickTime, any player |
| A base (a table of notes) | `Recipes.base`, a small text file | Obsidian |
| A canvas | `Course map.canvas`, a small text file | Obsidian |

[[What the files are]] explains each kind in more detail.

## Making your first vault

1. When no vault is open, Graphite shows its welcome screen. Choose **Create New Vault**.
2. Type a **Vault name**, such as *Notes*.
3. On iPad and iPhone it goes in Graphite's own folder, which the Files app shows under **On My iPad** › **Graphite**. **Choose Folder…** puts it somewhere else, such as iCloud Drive. On the Mac, use **Choose Folder…** to say where it goes.
4. Choose **Create**. The vault opens, empty and ready.

To switch between vaults later, tap the vault's name at the top of the sidebar (on iPhone, the title of the file list; on the Mac, the vault's name at the bottom of the sidebar) and pick another. **Manage Vaults…** adds and removes vaults. **Remove from List** only forgets a vault: its folder and files stay where they are.
