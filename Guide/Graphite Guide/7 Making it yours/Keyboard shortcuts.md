# Keyboard shortcuts

With a keyboard attached to the iPad, or on the Mac, these work everywhere. On iPad, hold ⌘ to see the shortcuts of the screen you are on.

## Notes and files

| Keys | Does |
| --- | --- |
| ⌘N | new note |
| ⌘O | Quick Switcher |
| ⌘P (⇧⌘P on the Mac) | Command Palette |
| ⇧⌘F | search all files |
| ⌘E | read or write |
| ⇧⌘G | the graph |
| ⌘, | Settings |

## Tabs

| Keys | Does |
| --- | --- |
| ⌘T | new tab |
| ⌘W | close the tab |
| ⇧⌘T | reopen it |
| ⌃Tab | next tab |
| ⌘1 to ⌘8, ⌘9 | a tab, the last tab |
| ⌘[ and ⌘] | back and forward |

## Writing

| Keys | Does |
| --- | --- |
| ⌘B, ⌘I | bold, italic |
| ⇧⌘H, ⇧⌘X | highlight, strikethrough |
| ⌃⌘C | inline code |
| ⌘/ | comment |
| ⌘K | link |
| ⌘L | tick a task |
| ⌃⌘1 to ⌃⌘6 | headings |
| ⌥⌘↑, ⌥⌘↓ | move a line up or down |

## Change them

Settings › **Keyboard Shortcuts** lists every command. Find one by name or by its keys, choose **Record Shortcut** and press the new keys, or remove or reset one. The shortcuts belong to the vault and are the same in Obsidian.
