# Plugins

## Core plugins: features you can turn off

As in Obsidian, every feature is a core plugin with a switch. Settings › **Core Plugins** lists them: Backlinks, Outline, Tags View, Word Count, Colors, Pencil Drawings, Audio Recorder, Read Aloud, Bases, Templates, Daily Notes, Calendar, Graph View, Map View, Canvas, Goodnotes and Notability Import, and more.

Turning a feature off hides it in Graphite and never changes your notes. A feature that is off costs nothing: it is not loaded until you turn it on. Features with options get their own page under **Core Plugins** in the Settings sidebar.

## Community plugins

Graphite can install and run many of Obsidian's community plugins, from the vault's own `.obsidian/plugins` folder. This is early work: plugins that need Obsidian's desktop app do not run.

1. Settings › **Community Plugins** › **Turn On Community Plugins**.
2. **Browse Community Plugins…** lists Obsidian's directory. Choose **Install** on the one you want, or install one from its GitHub repository.
3. Turn it on with its switch under **Installed Plugins**. **Options** opens its settings; **Remove** uninstalls it.

Plugins that Obsidian already installed in the vault show up there too. Community plugins are off until you turn them on, in each vault.

> [!info] What works
> The repository keeps a dated list of the plugins tried and how well each works: `Docs/Community-plugins.md` on [github.com/Graphite-Note/Graphite](https://github.com/Graphite-Note/Graphite).
