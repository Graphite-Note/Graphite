# Library and list

The sidebar shows your files in one of two ways. Switch with the two buttons at the top of the sidebar, **Show Files As** List or Library, or in Settings › Appearance › **Show Files As**.

## List

Obsidian's file list: folders that open and close, files by name. Touch and hold a file or folder (on the Mac, right-click it) for **Rename…**, **Move to…**, **Make a Copy** and **Delete**; drag a file onto a folder to move it.

## Library

Folders and files as tiles, as the Files app shows them, with a thumbnail of each note's and PDF's first page. Open a folder to go in; the back arrow goes up again. From a document, the house button at the start of the tab bar (**Library**) brings the library back.

Coming from Goodnotes, the library will feel familiar: your notebooks as covers, in folders. See [[Moving in from Goodnotes and Notability]].

## Tabs and splits

Several files can be open in tabs. **Split Right** shows two side by side, such as a PDF and the note about it; **Close This Side** ends the split. **More** › **Focus** hides everything but the page.
