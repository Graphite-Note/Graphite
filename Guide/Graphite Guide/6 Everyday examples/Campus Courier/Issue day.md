# Issue day

Every other Thursday. The layout is locked on Wednesday night; nothing changes after that but a mistake.

- [ ] 08:00 last read of every page, two people per page
- [ ] 09:30 export the pages, check every picture is there
- [ ] 10:00 send to the print shop
- [ ] 15:00 pick up the boxes and set the copies out in the halls
